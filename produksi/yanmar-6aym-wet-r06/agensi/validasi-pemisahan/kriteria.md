# Kriteria audit pemisahan paket r06
- Cocokkan GLB publikasi privat r06 dengan model paket melalui SHA-256 dan ID node/komponen. Bandingkan data model, sumber produksi, dan master yang dapat dibuka kembali dengan inventaris produksi. Catat setiap aset asli yang tersedia dalam bentuk yang sama, pindah, diubah, diduplikasi, atau hilang. Arsipkan jejak kerja yang tersedia dan nyatakan keterbatasan riwayat percakapan.
- Jalankan paket dari lokasi/distribusi independen dan subpath HTTP. Runtime tidak bergantung pada jalur /workspace, asal situs publik, akun produksi atau pengenal host. Bedakan referensi sejarah dari dependensi aktif.
- Audit batas modul. Mesin inti mengelola state, scene/model, jam simulasi, gerak, audio/effect, metadata dan seleksi. API memberi UI kemampuan start, jeda, lanjut, stop, reset, seleksi, kontrol tampilan dan pembacaan state. UI menyediakan elemen DOM dan gaya sendiri. Core boleh menerima target kanvas dan elemen milik render secara eksplisit; tidak boleh mencari tombol, label, panel atau markup studio. Kedua UI harus benar-benar memakai core dan GLB identik.
- Uji dua UI nyata dengan Chromium WebGL pada 1280×800 dan 390×844 DPR2. Verifikasi start, pause/resume, stop, reset, seleksi, state fallback dan beberapa matriks komponen pada pose yang sama. Bandingkan diamnya rumah tetap dan posisi kembali setelah reset. Catat model browser dan bedakan emulasi viewport dengan perangkat fisik.
- Pertahankan batas validasi r06, termasuk 696 pasangan belum diklasifikasikan, tafsir OEM, dan akses privat. Audit pemisahan tidak menilai ulang benturan seluruh mesin.
