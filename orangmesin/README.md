# orangmesin V3 — public frontend

Frontend continuation of the existing Pelaut Jago Mesin project. Brand, palette, typography and headline follow the owner’s V3 brief. Existing Shinko source is retained. Premium pages contain product information only.

Publish only `orangmesin/dist`, never the repository root. The root contains older premium simulator exports. Accounts and checkout stay closed without the protected API deployment.

The backend, Supabase migration, private simulator originals, tests and deployment runbook are preserved in the existing Sites source repository, pending approval before public GitHub publication. This PR intentionally contains only the frontend that is being published on the existing website.

Verified: desktop and mobile layout, ID/EN landing/commerce shell, catalog filter, closed payment state and no-WebGL fallback. WebGL interaction and live commerce are not verified. Original technical simulator text remains mainly Indonesian.
